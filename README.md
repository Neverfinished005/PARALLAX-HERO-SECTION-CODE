# AlphaKore company website

Static site (plain HTML, CSS and JS, no build step). Open `index.html`, or run `python -m http.server`.

- `index.html`: hero, about and journey, products, quote, team carousel, footer
- `portfolio.html`, `careers.html`, `company.html`, `contact.html`, `terms.html`: sub-pages, linked from the footer
- `404.html`: shown by Vercel for unknown addresses
- `assets/style.css`, `assets/common.js`, `assets/glass.js`: shared styles and behaviour
- `assets/team/`: team photos
- `assets/media/`: drop story photos and videos here (see the README inside)

The previous version of the site is in this repo's history on `main` before this change.
